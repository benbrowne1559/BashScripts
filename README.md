BashScripts

A repo containing all my developed Bash Scripts. Part of my journey to become a fully fledged DevOps Engineer.

Current Scripts:

FocusLock -> script that adds distracting sites to the /etc/hosts file for a specified period of time. After said period, the /etc/hosts file is restored 
to its previous state.

HealthCheck -> script that outputs information such as CPU/Memory Usage every hour to a rolling log file
